# Kontrak API platform Shareat

Kontrak endpoint, otorisasi, DTO, error, idempotency dan adapter berada di [bagian API SDD](docs/SDD.md#5-api-dan-kontrak-integrasi), dengan aturan bisnis pada [SRS](docs/SRS.md). Seluruh endpoint keuangan R2 tidak terdaftar pada deployment R1. OpenAPI executable dibuat ketika implementation schema tersedia; dokumen ini tidak mengklaim adanya API yang sudah berjalan.
